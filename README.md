# CSV Workbench

Локальный настольный инструмент для работы с CSV. Первый этап: открытие и просмотр CSV по 200 строк.

Запуск из корня проекта (Python 3.12+ и uv):

```sh
uv sync --locked --python 3.12 --extra dev
uv run --locked csv-workbench
```

Нажмите **Open CSV** и выберите CSV с запятыми и заголовком. Кодировка определяется автоматически: UTF-8, UTF-16/32 с BOM или вероятная Windows-1251, Windows-1252, KOI8-R либо CP866. Экспорт сохраняется в UTF-8.
При прокрутке вниз новые строки подгружаются автоматически. Внизу видны размер файла, общее число записей и число уже загруженных строк. Нажмите заголовок столбца, чтобы добавить фильтр или изменить сортировку. Точка отмечает фильтр, стрелка — сортировку. В **Selection…**
можно добавить несколько условий по подстроке, выбрать **All conditions (AND)** или **Any condition (OR)**, задать сортировку и видимые столбцы. Фильтры учитываются также в **Unique values…** и экспорте.
**Apply** применяет выборку ко всему файлу, **Reset** возвращает исходный вид. **Export CSV…** сохраняет всю текущую выборку в отдельный CSV, включая строки, которые ещё не подгрузились в таблицу.

**Preview SQL…** показывает запрос DuckDB для всей текущей выборки и параметры в порядке подстановки. Первый параметр — путь к CSV в UTF-8. Окно не выполняет запрос.

**SQL editor…** выполняет один `SELECT` по всему открытому файлу через таблицу `csv_data`. Столбцы имеют тип text; для вычислений используйте явное преобразование типов. Результат показывается отдельно, до 200 строк. **Cancel** прерывает фоновый запрос.

В меню **Session** можно сохранить или открыть файл `.csvsession`. Он хранит абсолютный путь к CSV и настройки визуальной выборки. Если CSV переместить, сессия не откроется по старому пути.

Для повторного применения преобразований сохраните запрос через **Save SQL…**. Откройте другой CSV с такими же столбцами, выберите **Open SQL…** в редакторе и нажмите **Run**. Каждый блок `WITH` может использовать результат предыдущего:

```sql
WITH cleaned AS (
    SELECT trim(category) AS category FROM csv_data
), populated AS (
    SELECT category FROM cleaned WHERE category <> ''
)
SELECT category, count(*) AS frequency FROM populated GROUP BY category;
```

В исходном виде таблицы дважды нажмите на ячейку и подтвердите правку клавишей Enter. **Export CSV…** сохраняет все строки с правками в новую копию. Чтобы применить фильтр, сортировку или SQL к правкам, откройте эту копию.

Проверки:

```sh
uv run --locked --extra dev pytest
uv run --locked --extra dev ruff check src tests
uv run --locked --extra dev ruff format --check src tests
```

Кнопка **Cancel** отменяет текущие чтение, подсчёт и экспорт.
Замеры больших файлов: [отчёт](BENCHMARK.md).

Этапы и критерии готовности описаны в [roadmap](ROADMAP.md). Проверить спецификации: `openspec validate --all --strict`.

Автономная сборка для текущей ОС:

```sh
uv sync --locked --python 3.12 --extra build
uv run --locked --extra build python scripts/build_desktop.py
```

Скрипт собирает приложение, запускает короткую проверку бинарника и сохраняет архив в `dist/`. На macOS распакуйте ZIP и откройте `csv-workbench.app` (сборка без нотариального заверения). На Windows и Linux распакуйте архив целиком и запустите `csv-workbench.exe` или `csv-workbench` из полученной папки. На Linux нужна совместимая настольная среда с системными библиотеками Qt. Матрица GitHub Actions собирает и проверяет пакеты на каждой ОС отдельно.

**Unique values…** показывает различные значения и их частоты по всей текущей выборке. **Only values occurring once** оставляет значения с частотой 1. При прокрутке таблица хранит до 600 строк, а отсортированные результаты и частоты временно хранятся на диске.
