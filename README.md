# CSV Workbench

Локальный настольный инструмент для работы с CSV. Первый этап: открытие и просмотр CSV по 200 строк.

Запуск из корня проекта (Python 3.12+ и uv):

```sh
uv sync --locked --python 3.12 --extra dev
uv run --locked csv-workbench
```

Нажмите **Open CSV** и выберите CSV или TSV. Диалог предложит разделитель (запятая, точка с запятой или табуляция) и покажет до 10 строк. Разделитель можно изменить вручную: выберите **Custom…** и введите один печатный ASCII-символ, например `|` или `:`. В **Quote character** можно заменить двойную кавычку другим печатным ASCII-символом, например апострофом. В **Encoding** можно выбрать кодировку вручную. Предпросмотр обновляется при изменении настроек. Если первая строка содержит данные, снимите флажок **First record contains column names**. Кодировка определяется автоматически: UTF-8, UTF-16/32 с BOM или вероятная Windows-1251, Windows-1252, KOI8-R либо CP866. Экспорт сохраняется в UTF-8.
При прокрутке вниз новые строки подгружаются автоматически. Внизу видны размер файла, общее число записей и число уже загруженных строк. Стрелка в заголовке переключает сортировку: по возрастанию, по убыванию, без сортировки. Удерживайте Alt (Option на macOS), чтобы сохранить другие ключи; номер у стрелки показывает приоритет. Кнопка **F** открывает фильтр столбца, а точка отмечает активный фильтр. В **Selection…**
можно добавить несколько условий по подстроке, выбрать **All conditions (AND)** или **Any condition (OR)**, задать сортировку и видимые столбцы. Фильтры учитываются также в **Unique values…** и экспорте.
**Apply** применяет выборку ко всему файлу, **Reset** возвращает исходный вид. **Export CSV…** сохраняет всю текущую выборку в отдельный CSV или TSV, включая строки, которые ещё не подгрузились в таблицу. Перед сохранением можно выбрать разделитель (в том числе свой), кодировку, символ кавычек и наличие заголовка. По умолчанию экспорт использует UTF-8 без BOM, запятую, двойные кавычки и заголовок.

Чтобы повторно использовать формат, нажмите **Save Preset…**, задайте имя и в следующий раз выберите его в списке **Preset**. Приложение хранит отдельные списки для открытия и экспорта между запусками. Выбор пресета при открытии сразу обновляет предпросмотр. В меню **Manage…** можно переименовать или удалить выбранный пресет, назначить его по умолчанию или сбросить назначение. Пресет по умолчанию применяется при каждом открытии соответствующего диалога.

Для переноса на другой компьютер выберите **Manage… → Export Presets to JSON…**. Файл содержит оба списка и оба назначения по умолчанию. **Import Presets from JSON…** объединяет списки и берёт назначения из файла. Пресеты, которых нет в файле, остаются в списках. Если имена совпадут, приложение покажет их и предложит подтвердить замену; отказ отменяет весь импорт.

**Preview SQL…** показывает запрос DuckDB для всей текущей выборки и параметры в порядке подстановки. Первый параметр — путь к CSV в UTF-8. Окно не выполняет запрос.

**SQL editor…** выполняет один `SELECT` по всему открытому файлу через таблицу `csv_data`. Столбцы имеют тип text; для вычислений используйте явное преобразование типов. Результат показывается отдельно, до 200 строк. **Cancel** прерывает фоновый запрос.

В меню **Session** можно сохранить или открыть файл `.csvsession`. Он хранит абсолютный путь к CSV, формат открытия и настройки визуальной выборки. Если CSV переместить, сессия не откроется по старому пути.

Для повторного применения преобразований сохраните запрос через **Save SQL…**. Откройте другой CSV с такими же столбцами, выберите **Open SQL…** в редакторе и нажмите **Run**. Каждый блок `WITH` может использовать результат предыдущего:

```sql
WITH cleaned AS (
    SELECT trim(category) AS category FROM csv_data
), populated AS (
    SELECT category FROM cleaned WHERE category <> ''
)
SELECT category, count(*) AS frequency FROM populated GROUP BY category;
```

Дважды нажмите на ячейку и подтвердите правку клавишей Enter. Фильтр и сортировка пересчитываются в фоне; правки остаются при смене выборки. **Export CSV…** сохраняет текущую выборку с правками в отдельный файл. В меню **File → Save** сохраняет текущий файл, а **Save As…** записывает его по новому пути и переключает документ на этот путь. Обе команды сохраняют все строки и столбцы в исходном порядке, включая скрытые фильтром. Сохраняются разделитель, символ кавычек и наличие заголовка. Если кодировка выбрана вручную, сохраняется и она; в режиме **Auto** файл записывается в UTF-8. **Edit → Undo / Redo** отменяет и повторяет правки, в том числе после сохранения. SQL работает с последней сохранённой версией CSV.

В меню **Edit** можно копировать и вставлять диапазоны через буфер обмена (TSV), очищать выделенные ячейки, добавлять, дублировать и удалять строки. Вставка начинается с текущей ячейки и должна помещаться в загруженную область. Добавленные и дублированные строки идут в конец исходного порядка; в режиме фильтрации они видны только при совпадении с фильтром. Для дублирования покажите все столбцы. Каждая операция отменяется целиком одним **Undo**.

Проверки:

```sh
uv run --locked --extra dev pytest
uv run --locked --extra dev ruff check src tests
uv run --locked --extra dev ruff format --check src tests
```

Кнопка **Cancel** отменяет текущие чтение, подсчёт и экспорт.
Замеры больших файлов: [отчёт](BENCHMARK.md).

Этапы и критерии готовности описаны в [roadmap](ROADMAP.md). Проверить спецификации: `openspec validate --all --strict`.

Автономная сборка для текущей ОС:

```sh
uv sync --locked --python 3.12 --extra build
uv run --locked --extra build python scripts/build_desktop.py
```

Скрипт собирает приложение, запускает короткую проверку бинарника и сохраняет архив в `dist/`. На macOS выберите архив своей архитектуры: **macOS-ARM64** для Apple Silicon или **macOS-X64** для Intel. Для текущей версии Qt требуется macOS 14 или новее. Распакуйте ZIP и откройте `csv-workbench.app` (сборка без нотариального заверения). На Windows и Linux распакуйте архив целиком и запустите `csv-workbench.exe` или `csv-workbench` из полученной папки. На Linux нужна совместимая настольная среда с системными библиотеками Qt. Матрица GitHub Actions собирает и проверяет пакеты на каждой ОС отдельно.

**Unique values…** показывает различные значения и их частоты по всей текущей выборке. **Only values occurring once** оставляет значения с частотой 1. При прокрутке таблица хранит до 600 строк, а отсортированные результаты и частоты временно хранятся на диске.
