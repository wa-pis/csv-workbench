Локальное настольное приложение для просмотра, редактирования и анализа CSV и TSV.

## Запуск из исходников

Из корня проекта, с Python 3.12+ и uv:

```sh
uv sync --locked --python 3.12 --extra dev
uv run --locked csv-workbench
```

На macOS `uv.lock` временно закрепляет официальную snapshot-сборку PySide6 с Qt 6.12.1: стабильный Qt 6.12.0 содержит [ошибку владения Accessibility-интерфейсами таблиц](https://qt-project.atlassian.net/browse/QTBUG-149612). Используйте `uv sync --locked`, чтобы получить проверенную версию. После публикации стабильного PySide6 6.12.1 snapshot следует заменить с повтором нативного регрессионного теста.

Нажмите **Open CSV** и выберите CSV или TSV либо перетащите один файл в окно приложения. Диалог предложит разделитель (запятая, точка с запятой или табуляция) и покажет до 10 строк. Разделитель можно изменить вручную: выберите **Custom…** и введите один печатный ASCII-символ, например `|` или `:`. В **Quote character** можно заменить двойную кавычку другим печатным ASCII-символом, например апострофом. В **Encoding** можно выбрать кодировку вручную. Предпросмотр обновляется при изменении настроек. Если первая строка содержит данные, снимите флажок **First record contains column names**. Кодировка определяется автоматически: UTF-8, UTF-16/32 с BOM или вероятная Windows-1251, Windows-1252, KOI8-R либо CP866.

**File → Open Recent** показывает закреплённые файлы сверху и до 10 остальных недавних файлов. В **Manage Recent Files…** можно закрепить или открепить файл, удалить отдельную запись или очистить незакреплённую историю. Эти действия меняют только список. Выбор файла сразу открывает его с последним использованным разделителем, кодировкой, символом кавычек и настройкой заголовка. Чтобы выбрать другой формат, откройте файл через **Open CSV**.

Каждый новый файл открывается в отдельной вкладке. При переключении сохраняются фильтры, сортировка и несохранённые правки. Звёздочка в названии вкладки отмечает правки; перед закрытием приложение спросит, можно ли их отбросить. Повторное открытие уже открытого файла переключает на его вкладку. Если нужно изменить формат этого файла, закройте вкладку и откройте файл заново.

В контекстном меню заголовка **Pin Column Left** закрепляет столбец слева при горизонтальной прокрутке; **Unpin Column** открепляет его. Закрепление сохраняется в сессии и не влияет на порядок экспорта. **Hide Column** скрывает столбец, а **Manage Columns…** позволяет найти и снова показать его. Перетащите заголовок, чтобы поменять порядок столбцов. Раскладка сохраняется в сессии и учитывается при экспорте; Save сохраняет исходный порядок столбцов файла.

Переключатель **Table / Text** показывает таблицу или исходный текст сохранённого файла. Text доступен только для чтения и ограничен первыми 128 Ки символов; кодировка берётся из настроек открытия. Фильтры и несохранённые правки в текст не входят. Повторное переключение на Text обновляет предпросмотр с диска.

**Edit → Transpose Selection…** открывает выделенный прямоугольный диапазон в транспонированном виде: поля по вертикали, записи по горизонтали. Просмотр доступен для уже загруженных строк и ограничен 10 000 ячеек; правки учитываются, исходная таблица не меняется.

**Edit → Record View…** показывает видимые поля текущей строки списком, включая многострочные значения и несохранённые правки. В этом окне значения доступны только для чтения.

**Edit → Go to Row…** (`⌘G` на macOS, `Ctrl+G` на Windows и Linux) выделяет строку по номеру в текущей выборке. Нумерация начинается с 1 и учитывает фильтры и сортировку. Можно указать `столбец:строка`, например `2:1000`; номер столбца соответствует его текущему положению в таблице.

Правый клик по ячейке → **Filter by** добавляет точное условие **Equals this value** или **Does not equal this value**. Оно действует по всей выборке, в том числе при подсчёте частот и экспорте. Отдельное условие можно удалить в **Selection…**. Пустые значения отличаются от текста `NULL`.

**Edit → Find…** (`⌘F` или `Ctrl+F`) подсвечивает текст в видимых столбцах без учёта регистра. **Next** (или Enter) и **Previous** ищут по всей текущей выборке, включая неподгруженные строки и несохранённые правки. **Stop** отменяет поиск, **Close** или Escape убирает панель.

**Edit → Find and Replace…** готовит замену буквального текста без учёта регистра по всем строкам текущей выборки, включая неподгруженные строки и правки. Обрабатываются только видимые столбцы. Выберите первое совпадение от начала выборки или все совпадения, затем **Preview**: диалог показывает первые 100 изменений и общее количество. **Replace One / Replace All** применяет подготовленные изменения одним шагом Undo/Redo; **Stop** отменяет подготовку. Пустая замена удаляет найденный текст. Фильтры и сортировка пересчитываются после замены; исходный CSV меняется только после Save. Правки и значения истории Undo/Redo хранятся в SQLite на временном диске; замена читается порциями, а Undo/Redo переключает снимки. Для запросов используется ограниченный кэш Parquet и лимит DuckDB 512 МиБ (это не лимит всей RAM процесса). Временный диск растёт с историей и освобождается после закрытия документа и завершения его фоновых задач. Первое Save сохраняет отдельную копию исходного CSV для Undo после сохранения.


После сбоя приложение предлагает восстановить несохранённые правки отдельно для каждого файла: **Yes** восстанавливает, **No** удаляет контрольную точку, **Cancel** оставляет её на следующий запуск. Восстанавливаются правки ячеек и строк, Undo/Redo, формат и настройки выборки. Исходный CSV не меняется до явного **Save**. Если исходный файл изменился или отсутствует, контрольная точка сохраняется, но автоматически не применяется.

Журнал находится в подкаталоге `recovery` системного каталога локальных данных приложения. Запись идёт в фоне после подтверждённых правок; сбой до её завершения может потерять последние изменения. Обычные правки не копируют CSV. Для структурной истории после Save может сохраняться дополнительная копия базы. Успешное Save, Undo до чистого состояния или закрытие с подтверждённым отказом от правок удаляет контрольную точку. Ошибка записи журнала показывается явно; текущие правки остаются в памяти.

**Session → Save workspace…** сохраняет все открытые вкладки в один `.csvsession`: их порядок, активную вкладку, формат файлов и визуальную выборку каждой таблицы. Вкладки можно перетаскивать, чтобы изменить их порядок. **Restore workspace…** заменяет текущее окно после успешного открытия всех файлов. При отмене или ошибке текущие вкладки остаются открытыми. Несохранённые правки ячеек в файл сессии не входят — для них используйте **Save** или **Save As…**.
В редакторе ячейки **Edit → Complete Value** или **Ctrl+Space** показывает до 100 уникальных значений того же столбца по текущему префиксу. Поиск идёт в фоне по всей текущей выборке с несохранёнными правками, включая неподгруженные строки. Префикс буквальный и регистрозависимый; пустой префикс показывает первые значения в порядке Unicode. Если Ctrl+Space перехватывает ОС (например, переключение раскладки macOS), используйте меню. После вызова изменение текста перезапускает поиск. Стрелками выберите подсказку и нажмите Enter, чтобы вставить её в редактор; ещё один Enter подтверждает ячейку и создаёт один шаг Undo. Escape закрывает подсказки/отменяет запрос, повторный Escape отменяет редактирование; общая кнопка **Cancel** также останавливает поиск. При большом числе значений строка состояния показывает ограничение в 100 подсказок. Подсказки работают и в закреплённом столбце.

При прокрутке вниз новые строки подгружаются автоматически. Внизу видны размер файла, общее число записей и число уже загруженных строк. Стрелка в заголовке переключает сортировку: по возрастанию, по убыванию, без сортировки. Удерживайте Alt (Option на macOS), чтобы сохранить другие ключи; номер у стрелки показывает приоритет. Кнопка **F** открывает фильтр столбца, а точка отмечает активный фильтр. В **Selection…**
можно добавить несколько условий по подстроке, выбрать **All conditions (AND)** или **Any condition (OR)**, задать сортировку и видимые столбцы. Фильтры учитываются также в **Unique values…** и экспорте.
**Apply** применяет выборку ко всему файлу, **Reset** возвращает исходный вид. **Export CSV…** сохраняет всю текущую выборку в отдельный CSV или TSV, включая строки, которые ещё не подгрузились в таблицу. Перед сохранением можно выбрать разделитель (в том числе свой), кодировку, символ кавычек и наличие заголовка. По умолчанию экспорт использует UTF-8 без BOM, запятую, двойные кавычки и заголовок.

Чтобы повторно использовать формат, нажмите **Save Preset…**, задайте имя и в следующий раз выберите его в списке **Preset**. Приложение хранит отдельные списки для открытия и экспорта между запусками. Выбор пресета при открытии сразу обновляет предпросмотр. В меню **Manage…** можно переименовать или удалить выбранный пресет, назначить его по умолчанию или сбросить назначение. Пресет по умолчанию применяется при каждом открытии соответствующего диалога.

Для переноса на другой компьютер выберите **Manage… → Export Presets to JSON…**. Файл содержит оба списка и оба назначения по умолчанию. **Import Presets from JSON…** объединяет списки и берёт назначения из файла. Пресеты, которых нет в файле, остаются в списках. Если имена совпадут, приложение покажет их и предложит подтвердить замену; отказ отменяет весь импорт.

**Preview SQL…** показывает запрос DuckDB для всей текущей выборки и параметры в порядке подстановки. Первый параметр — путь к CSV в UTF-8. Окно не выполняет запрос.

**SQL editor…** выполняет один `SELECT` по всему открытому файлу через таблицу `csv_data`. Столбцы имеют тип text; для вычислений используйте явное преобразование типов. Результат показывается отдельно, до 200 строк. **Cancel** прерывает фоновый запрос.

В меню **Session** можно сохранить или открыть файл `.csvsession`. Он хранит абсолютный путь к CSV, формат открытия и настройки визуальной выборки. Если CSV переместить, сессия не откроется по старому пути.

Для повторного применения преобразований сохраните запрос через **Save SQL…**. Откройте другой CSV с такими же столбцами, выберите **Open SQL…** в редакторе и нажмите **Run**. Каждый блок `WITH` может использовать результат предыдущего:

```sql
WITH cleaned AS (
    SELECT trim(category) AS category FROM csv_data
), populated AS (
    SELECT category FROM cleaned WHERE category <> ''
)
SELECT category, count(*) AS frequency FROM populated GROUP BY category;
```

Нажмите Enter/F2 или дважды щёлкните по ячейке, чтобы начать редактирование. Enter подтверждает правку одной операцией Undo, Escape отменяет её. Для длинного текста или переносов строк нажмите `Shift+Enter` (либо **Edit → Open in Value Editor…**). Подтверждение меняет ячейку одной операцией Undo; Escape закрывает диалог без правки. Фильтр и сортировка пересчитываются в фоне; правки остаются при смене выборки. **Export CSV…** сохраняет текущую выборку с правками в отдельный файл. В меню **File → Save** сохраняет текущий файл, а **Save As…** записывает его по новому пути и переключает документ на этот путь. Обе команды сохраняют все строки и столбцы в исходном порядке, включая скрытые фильтром. Сохраняются разделитель, символ кавычек и наличие заголовка. Если кодировка выбрана вручную, сохраняется и она; в режиме **Auto** файл записывается в UTF-8. **Edit → Undo / Redo** отменяет и повторяет правки, в том числе после сохранения. SQL работает с последней сохранённой версией CSV.

**File → Compare Saved CSV…** сравнивает текущий сохранённый файл со вторым CSV/TSV по выбранному ключу. Формат второго файла настраивается отдельно. Сравниваются все сохранённые строки без фильтров и несохранённых правок. Нужны одинаковые имена столбцов и уникальный непустой ключ; порядок столбцов может отличаться. Окно показывает количество добавленных, удалённых и изменённых записей и значения до/после. Результат хранится на диске и читается страницами; **Cancel** отменяет подготовку.

**File → Export JSON… / Export Markdown…** выгружает всю текущую выборку с фильтрами, сортировкой, выбранными столбцами и правками, включая неподгруженные строки. Вывод UTF-8 идёт в фоне порциями; **Cancel** отменяет операцию, сохраняя прежний выходной файл.

**Edit → Copy As** копирует выделение как TSV, CSV, JSON или Markdown в текущем порядке столбцов и с правками. JSON и Markdown содержат имена полей; Ctrl/⌘+C по-прежнему копирует TSV без заголовка. Лимит — 10 000 ячеек и 4 МиБ UTF-8; при превышении буфер обмена не меняется.

В меню **Edit** можно копировать и вставлять диапазоны через буфер обмена (TSV), очищать выделенные ячейки, добавлять, дублировать и удалять строки. Вставка начинается с текущей ячейки и должна помещаться в загруженную область. Добавленные и дублированные строки идут в конец исходного порядка; в режиме фильтрации они видны только при совпадении с фильтром. Для дублирования покажите все столбцы. Каждая операция отменяется целиком одним **Undo**.

Проверки:

```sh
uv run --locked --extra dev pytest
uv run --locked --extra dev ruff check src tests
uv run --locked --extra dev ruff format --check src tests
```

Тяжёлые операции вкладок выполняются по очереди. Нижняя строка показывает ожидание, а **Cancel** отменяет активные и ожидающие операции текущей вкладки. Переключаться между вкладками и читать уже подготовленные страницы можно во время обработки.
Замеры больших файлов: [отчёт](BENCHMARK.md).

Этапы и критерии готовности описаны в [roadmap](ROADMAP.md). Проверить спецификации: `openspec validate --all --strict`.

Автономная сборка для текущей ОС:

```sh
uv sync --locked --python 3.12 --extra build
uv run --locked --extra build python scripts/build_desktop.py
```

Скрипт собирает приложение, проверяет запуск бинарника и сохраняет архив в `dist/`. GitHub Actions выполняет ту же проверку отдельно для каждой платформы.

**Unique values…** показывает различные значения и их частоты по всей текущей выборке. **Only values occurring once** оставляет значения с частотой 1. При прокрутке таблица хранит до 600 строк, а отсортированные результаты и частоты временно хранятся на диске.

### Полировка таблицы

Стрелки, Tab/Shift+Tab и Page Up/Down переходят через границы буфера с подгрузкой строк. Home/End переходят в начало/конец текущей выборки.

В **Edit** доступны выбор строки, столбца, загруженной таблицы и Extend/Shrink Selection. Расширение проходит ступени «столбец → строка → таблица»; сужение возвращает исходное выделение. Клавиши: Option+↑/↓ на macOS, Ctrl+Alt+↑/↓ на Windows/Linux. Выделение ограничено буфером (до 600 строк); его размер показан внизу окна. Shift со стрелками не переносит выделение за границу буфера.

Контекстное меню ячейки содержит редактирование, копирование/вставку, очистку, операции со строками, выделение, фильтр и Undo/Redo. ПКМ внутри диапазона сохраняет выделение, снаружи выбирает ячейку под указателем. Меню можно вызвать клавишей Menu или Shift+F10, в том числе из встроенного редактора ячейки: текущий ввод подтверждается перед показом меню и отменяется одним Undo. Поля поиска и другие поля окна не вызывают меню таблицы. Недоступные действия отключены, в том числе при просмотре unique.

### Диагностика клавиатуры на macOS

Перед запуском задайте `CSV_WORKBENCH_KEY_LOG` — путь к JSONL-журналу. По умолчанию диагностика выключена. Например, для распакованной сборки в текущем каталоге:

```sh
CSV_WORKBENCH_KEY_LOG=/tmp/csv-keyboard.jsonl ./csv-workbench.app/Contents/MacOS/csv-workbench
```

Откройте CSV, выберите ячейку и нажмите Shift+F10; повторите во встроенном редакторе. Журнал содержит коды Qt/native, модификаторы, классы фокуса/получателя, неоднозначность shortcut и этапы `cell_menu_requested`, `cell_menu_target`, `cell_menu_opening`, `cell_menu_closed`. Текст событий, пути CSV и значения ячеек не записываются. Коды обычных клавиш тоже являются диагностическими данными: включайте запись только на время проверки. Размер — до 1 МиБ плюс одна резервная копия `.1`; директория должна существовать. Ошибка открытия журнала выводится в stderr и не мешает запуску.

Для сравнения доставки нажмите также стрелку вниз. Отсутствие F10 при наличии других событий указывает на проблему до Qt shortcut. `Shortcut` с `ambiguous=true` означает конфликт сочетаний; `cell_menu_target` с `valid=false` — отсутствие целевой ячейки. `cell_menu_opening` и события с получателем `QMenu` подтверждают работу popup даже когда снимок/accessibility главного окна его не показывает.

### Типы и проверка значений

В **Edit → Column Types / Validation…** задайте для столбцов `text`, `integer`, `number`, `date` или `boolean` и допустимость NULL. Правила сохраняются для каждой вкладки в сессии. Ошибки подсвечиваются в таблице; объяснение доступно в подсказке ячейки. Значения не преобразуются, редактирование и сохранение остаются доступны. Дата — `YYYY-MM-DD`, boolean — `true`/`false`, число — конечная десятичная запись с необязательной экспонентой без пробелов.

**Edit → Validate Current Selection** проверяет в фоне всю отфильтрованную выборку с несохранёнными правками, включая неподгруженные строки и настроенные скрытые столбцы. Внизу показываются число ошибок и проверенных строк, в подсказке — счётчики по столбцам. **Cancel** останавливает проверку; изменение данных, выборки или правил сбрасывает старый результат.

`NULL` (отсутствующее значение) и `""` (пустая строка) отображаются отдельно в таблице и предпросмотре формата открытия. **Set NULL / Clear cells** записывает NULL, **Set Empty String** или подтверждение пустого текста в редакторе — пустую строку; операции поддерживают Undo/Redo. В CSV пустое поле без кавычек означает NULL, пустое поле в кавычках — пустую строку. Save и Export сохраняют это различие.

### Агрегаты выделения

Выделите ячейки и выберите **Edit → Aggregate Selection (buffered)** или ту же команду в меню ячейки. Нижняя панель покажет Count всех выбранных ячеек, количество NULL, пустых строк, числовых и пропущенных текстовых значений, а также числовые Sum, Average, Min и Max. Учитываются несохранённые правки, включая закреплённые столбцы отфильтрованной/отсортированной таблицы.

Числа — строгая десятичная запись с необязательной экспонентой без пробелов, конечная в double; sum/average вычисляются с 38 значащими десятичными цифрами. Текст, NaN и бесконечности пропускаются. Если чисел нет, числовые агрегаты показывают `—`, а не ноль.

Расчёт выполняется в фоне, **Cancel** отменяет его. Изменение выделения, данных или буфера сбрасывает результат; для нового выделения запустите команду снова. Проверяются только выбранные ячейки **текущего буфера**, а не все строки CSV. Агрегирование не меняет документ и Undo.
