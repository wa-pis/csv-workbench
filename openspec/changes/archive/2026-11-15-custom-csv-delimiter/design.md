## Context
Предпросмотр использует Python csv, а операции над всем файлом используют DuckDB и Polars.

## Decisions
Пользовательский разделитель — один печатный ASCII-символ, кроме двойной кавычки. Polars принимает один байт; кавычка зарезервирована для полей. Табуляция остаётся готовым вариантом. Неверный ввод блокирует открытие. Апостроф экранируется в литерале DuckDB. Автоопределение оставляем для трёх готовых вариантов.
