## Why

Пользователь может проверить, как визуальные настройки превращаются в запрос ко всему CSV.

## What Changes

- Добавить окно SQL текущей выборки с параметрами в порядке подстановки.
- Не выполнять запрос при открытии окна.

## Capabilities

### Modified Capabilities

- `csv-preview`: предпросмотр SQL визуальной выборки.

## Impact

Генерация SQL DuckDB и окно PySide6; новых зависимостей нет.
