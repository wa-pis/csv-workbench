# Design

Повторно использовать editable_query и immutable snapshot дисковых правок. Удалить сортировку строк только в запросе подсказок: фильтры и значения остаются теми же. Если текущая выборка уже материализована, читать её Parquet.

Не строить полный DISTINCT высококардинального столбца. DuckDB COPY потоково записывает только совпавший столбец во временный Parquet; Polars читает его пакетами по 8192 строки. Сохраняются только 101 наименьшее различное значение; 101-е показывает усечение. Это исключает материализацию всего результата Python API DuckDB 1.x. Сравнение префикса регистрозависимое, буквальное (не LIKE); порядок подсказок — Unicode code point. Память Python ограничена пакетом и списком кандидатов, DuckDB использует штатный лимит и временный диск. Parquet удаляется при успехе, ошибке и отмене; размер временного файла растёт с объёмом совпавших значений.

Отдельные экземпляры одного delegate обычной и закреплённой таблицы создаёт редактор с popup подсказок. После явного вызова изменения текста перезапускают поиск с debounce. Escape закрывает подсказки/отменяет поиск, повторный Escape отменяет редактор. Закрытие редактора, сброс модели, смена выборки/правок отменяют запрос. Каждый ответ проверяет поколение редактора, префикс и состояние документа; фоновые задачи держат собственные ссылки на снимки. Текст и результат не передаются между вкладками.

Существующий executor тяжёлых задач и Cancellation предотвращают конкурирующие неограниченные сканы. Общая Cancel отменяет и подсказки. При смене вкладки popup закрывается; редактор теряет фокус и отменяет запрос.
