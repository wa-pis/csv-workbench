# Приёмка изоляции производных результатов — 2026-11-27

[Первоначальный прогон ARM `d507a63`](../2026-11-27-bound-wide-csv-schema-detection/manual-check.md) подтвердил unique после Save As и сохранение Undo/Redo на CSV 600 × 4000.

[Итоговый прогон ARM `1b7832e`](../2026-11-27-keep-wide-csv-accessibility-responsive/manual-check.md) дополнительно подтвердил активную отмену unique и сортировки на CSV 6000 × 4000 / 2,47 ГБ, навигацию после отмены и отсутствие позднего результата. Контрольная несохранённая правка первой ячейки учитывалась в частоте unique (`000001: 9`), но не накладывалась на первую ячейку производной таблицы. После возврата в CSV Undo/Redo восстановили ожидаемые значения; контрольная правка убрана через Undo, исходный файл не изменён.

Точная сборка, SHA-256, состояния операций и ограничения ручного наблюдения приведены в итоговом отчёте. Проверки SQL и сравнения файлов для этой регрессии покрыты юнит-тестами; вручную эти представления в этом прогоне не проверялись.
