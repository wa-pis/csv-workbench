- Диалог типов позволяет выбрать все пять типов и запретить NULL.
- В основной таблице wrong/2023-02-29/yes/NULL подсвечены красным. Корректные число, високосная дата и TRUE не подсвечены.
- NULL и пустая строка отображаются соответственно `NULL` и `""`; запрет NULL помечает только отсутствующее значение, пустой text остаётся корректным.

Первый отдельный клик Cancel был уже после завершения быстрого прохода; отмена подтверждена повторным запуском с немедленным нажатием.

Вкладка закрыта, затем Session → Restore workspace восстановил файл, все пять типов и nullable. Проверены визуально значения в диалоге, а также сохранённый JSON. Новый полный проход после восстановления снова дал 4 ошибки / 5 млн строк и ту же подсветку.
