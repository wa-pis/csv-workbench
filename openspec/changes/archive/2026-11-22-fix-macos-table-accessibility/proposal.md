## Why

Сборка 3b55992 дважды упала при чтении macOS Accessibility таблицы большого CSV. Стек libqcocoa → AppKit совпадает с QTBUG-149612; нативный минимальный тест на установленном Qt 6.12.0 детерминированно обнаруживает удалённый интерфейс таблицы.

## What Changes

- Зафиксировать для macOS официальную неизменяемую сборку PySide6, содержащую Qt 6.12.1 с upstream-исправлением владения интерфейсами.
- Добавить нативный регрессионный тест выбранных ячеек, смены числа столбцов и закреплённой таблицы; запускать его также из автономной сборки.
- Повторить ручную проверку автодополнения и отмены на большом CSV.

## Capabilities

### Modified Capabilities

- `csv-preview`: безопасное чтение accessibility-дерева таблицы macOS.

## Impact

Зависимости macOS, lock-файл, нативная smoke-проверка и тесты. Движок CSV и сохранение файлов не меняются. Windows/Linux продолжают использовать стабильный PySide6. Snapshot заменяется стабильным PySide6 6.12.1 после публикации, с повтором нативного теста.
