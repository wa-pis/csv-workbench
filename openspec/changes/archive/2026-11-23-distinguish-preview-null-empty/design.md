## Decisions

Python 3.12 csv.reader не поддерживает чтение QUOTE_NOTNULL. Стандартный strict reader продолжает разбирать значения и проверять синтаксис; дополнительный проход по исходному тексту одной записи восстанавливает только признаки пустых незаключённых полей. Кавычка открывает quoted field только в начале поля; удвоенные кавычки и переносы внутри кавычек не разделяют поля. Исходные записи доступны через reader.line_num. Весь образец ограничен 128 Ки символов, вывод — 10 записями.

NULL передаётся модели как None, пустая строка как ''. Заголовки остаются строками, padding отсутствующих полей использует None. Физическая пустая строка соответствует NULL для одноколоночного CSV; в многоколоночном CSV пустые строки пропускаются.
