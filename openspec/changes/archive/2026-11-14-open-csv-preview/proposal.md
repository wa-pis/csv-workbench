## Why

Работу с CSV вне IDE нужно начать с проверяемого сценария: открыть локальный файл, увидеть столбцы и просмотреть строки. Он станет основой для фильтров, сортировки и экспорта.

## What Changes

- Создать Python-пакет с запуском через `uv run csv-workbench`.
- Добавить окно с выбором локального CSV и просмотром по страницам.
- Сообщать об ошибках чтения, сохраняя последний успешно открытый набор данных.
- Первый этап охватывает UTF-8 (включая BOM), CSV с запятой и строкой заголовка. Настройки формата, фильтры, сортировка и экспорт остаются за его пределами.

## Capabilities

### New Capabilities

- `csv-preview`: открытие локального CSV и просмотр строк по страницам без изменения файла.
