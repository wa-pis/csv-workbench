## Decisions
Один тяжёлый рабочий поток на окно. Чтение страниц готового Parquet остаётся в локальном пуле вкладки. Cancel снимает ожидающие задачи выбранной вкладки и прерывает выполняющуюся через существующий токен. Параметризованный запрос с LIMIT 0 получает имена столбцов без получения данных. Замер использует одинаковую пару запросов до и после.
