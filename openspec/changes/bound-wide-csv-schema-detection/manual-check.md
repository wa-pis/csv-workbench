## Ограничения

8 MiB — целевой размер блока префикса схемы; отдельная полная CSV-запись может быть больше. Ошибки в последующих записях обнаруживаются при их чтении. Преобразование legacy-кодировки в UTF-8 сохраняет существующую временную копию источника. Backend SQL/сравнения файлов не переведён на широкий потоковый путь этим исправлением. Новые замеры 5/20 млн строк, временного диска GUI и полный сценарий VoiceOver в этот прогон не входят.
