## ADDED Requirements

### Requirement: Изоляция отображения производных результатов от правок CSV

Приложение SHALL показывать производные результаты unique, SQL и сравнения файлов без повторного наложения правок исходного CSV по координатам результата. Исходная таблица SHALL сохранять правильное отображение своих правок при временной блокировке редактирования. Переключение представления SHALL сохранять историю документа и Undo/Redo.

#### Scenario: Unique после правки и сохранения
- **WHEN** пользователь изменил ячейку, сохранил документ через Save As и открыл unique
- **THEN** каждая ячейка unique показывает значение результата группировки
- **AND** совпадение номера строки или столбца с прежней правкой не меняет результат

#### Scenario: Возврат к исходной таблице
- **WHEN** пользователь возвращается из производного результата к CSV
- **THEN** исходная таблица показывает эффективные значения по стабильным адресам исходных ячеек
- **AND** история правок, Undo/Redo и состояние сохранения не теряются

#### Scenario: Фоновая операция временно запрещает редактирование
- **WHEN** исходная таблица временно блокирует редактирование во время фоновой операции
- **THEN** её видимые ячейки продолжают учитывать правки документа
