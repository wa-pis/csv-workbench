# Полировка таблицы: сравнение с JetBrains

Сверка 20 ноября 2026 года: публичная документация DataGrip/IntelliJ IDEA 2026.3 и исходный код CSV Workbench. Это проверка документированных сценариев; ручной сравнительный прогон двух приложений не выполнялся. Клавиши текстового редактора IDE не считаются автоматически клавишами таблицы.

| Сценарий | Ориентир JetBrains | Исходное состояние CSV Workbench | Критерий полировки |
|---|---|---|---|
| Клавиатурная навигация | Табличный редактор, переход к строке; диалог Go To Row поддерживает `column:row` | Home/End и Go to Row уже работают со всей выборкой; остальные переходы делегированы Qt и не имеют контракта на стыках буфера | Стрелки, Tab/Shift+Tab, Page Up/Down переходят через буфер; сохраняется столбец. Go to Row принимает также номер видимого столбца |
| Выделение | Extend/Shrink Selection: ячейка → столбец → строка → таблица; выбор столбца через заголовок | Стандартные диапазоны Qt; нет явных действий расширения и границ выделения | Явные Select Row/Column, Extend/Shrink; безопасное ограничение загруженными строками, понятная статистика |
| Редактирование | Enter начинает и подтверждает редактирование; Escape отменяет; двойной щелчок; Shift+Enter открывает Value Editor | Есть двойной щелчок и Value Editor; Enter и F2 не проверены явным контрактом | Enter/F2 и двойной щелчок запускают редактор; Escape не создаёт правку/Undo; подтверждение даёт один Undo; блокировка read-only/занятой таблицы |
| Контекстное меню | Основные действия ячейки доступны из меню: Edit, Copy/Paste, Value Editor, операции строк и Filter by | Меню ячейки содержит только Filter by; остальные команды есть в Edit | Одинаковые QAction в меню и клавишах; ПКМ внутри диапазона сохраняет его, снаружи выбирает целевую ячейку; клавиатурный вызов Menu/Shift+F10 |

## Порядок работ

1. `polish-csv-keyboard-navigation`: адресация и границы буфера.
2. `polish-csv-selection`: явные действия и ограничение выделения.
3. `polish-csv-cell-editing`: контракт редактора, подтверждения и отмены.
4. `polish-csv-context-menus`: единые действия, корректная цель и доступность.

Каждый этап имеет отдельное изменение OpenSpec и юнит-тесты Qt в offscreen. Проверяются отфильтрованная/отсортированная выборка, перестановка и закрепление столбцов, пустая и занятая таблица. Ручной прогон JetBrains и автономных сборок — отдельная проверка, не подменяется offscreen-тестами.

## Намеренные отличия

- Home/End продолжают переходить в начало/конец всей выборки: это уже согласованное поведение CSV Workbench. Tab на краю файла не добавляет строку.
- Выделение относится к загруженному буферу, максимум 600 строк. Команды копирования и редактирования диапазонов сохраняют существующие ограничения; операции над всей выборкой выполняются через фильтры, замену и экспорт. Виртуальное выделение миллионов строк — отдельный будущий этап.
- Сочетания Extend/Shrink: Option+↑/↓ на macOS; Ctrl+Alt+↑/↓ на Windows/Linux, чтобы не конфликтовать с закрытием вкладки. Все действия доступны в Edit.
- Пересчёт фильтра после правки может убрать строку из таблицы. Сохранение и Undo сохраняют прежнюю семантику и дисковую историю.
